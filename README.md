J'ACCUSE! — Python Detective Game

FILES
- jaccuse_game.py: Complete playable Python source code.
- JAccuse_Project_Presentation.pptx: Project presentation.

HOW TO RUN
1. Install Python 3 if it is not already installed.
2. Save jaccuse_game.py.
3. Open Terminal / Command Prompt in that folder.
4. Run: python jaccuse_game.py

No external Python packages are required.

GAMEPLAY
- Read the mystery, suspects and evidence.
- Type a suspect's name to make an accusation.
- You have two attempts for each case.
- The game shows the explanation and final score.
